Projekt będzie składał się z dwóch wielkich części:
Część 1
System dla klientów lotniska

Wszystko, co pasażer może zrobić samodzielnie przez stronę internetową lub aplikację.


Część 2
System wewnętrzny lotniska

Wszystko, czego potrzebują pracownicy, kierownicy, służby operacyjne i administracja.


Obie części muszą korzystać ze wspólnego zaplecza: bazy danych, serwera, mechanizmów autoryzacji i komunikacji między modułami.
